# Changelog

All notable changes to this project are documented here. Versions follow semantic versioning.

## [1.0.0] - 2026-10-25

### Added
- `python/sk_msd_verification.py`: Monte Carlo of the three MSD regimes (report Sec. 5.5).
- `python/ml_exact.py`: exact MSD for any resting-time law by Talbot inversion (Sec. 6).
- `python/ml_monte_carlo.py`: Monte Carlo check of the Mittag-Leffler extension (App. D.5).
- `python/ml_figure_data.py`: data for the TikZ figures `fig:ML-raster` and `fig:ML-regimes`.
- `matlab/pole_maps.m`: Mellin–Barnes pole maps (App. C).
- Generated figures in `figs/` and data in `results/`, matching report v2.3.
